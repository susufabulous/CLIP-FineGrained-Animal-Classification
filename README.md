# Fine-Grained Animal Classification using CLIP ViT-B/32

本项目是一个基于 **OpenCLIP ViT-B/32** 骨干网络的单模型、鲁棒微调方案，专为大规模、长尾分布、含有标签噪声的细粒度动植物（昆虫、鸟类、鱼类等 750+ 类别）图像分类任务而设计。

## 🏆 方案与竞赛约束说明
本方案严格遵循以下设计要求：
1. **骨干网络限制**：严格使用 CLIP 的 **ViT-B/32** 作为视觉编码器，未引入其他或更大规模的视觉大模型。
2. **单模型推理**：采用纯单模型架构，不进行多模型集成，保证推理流程简洁高效。
3. **完全可复现**：整个训练、噪声样本动态降权及测试集预测流程均可通过代码一键复现。

## 🚀 主要技术特点
- **鲁棒微调 (Robust Fine-Tuning)**：仅解冻最后两个 Transformer Block (`ln_post` 及 `proj`)，兼顾预训练视觉先验与下游特定领域特征。
- **噪声样本启发式降权 (Noise-Weighting Strategy)**：通过验证式交叉熵损失动态检测异常样本，对疑似噪声数据进行自适应降权（如权重 0.2），抑制错误监督的负面影响。
- **高级数据增强与正则化**：结合 `CutMix`、`RandomErasing`、图像质量退化模拟以及空间几何变换，大幅提升模型在长尾分布上的泛化能力。
- **测试时增强 (TTA)**：在验证集上通过网格搜索自动评估并选定最优的推理视图策略（最终采用 `five_crop_flip` 策略，验证准确率达 **71.47%**）。
